# 🐍 스네이크 게임

HTML, CSS, JavaScript만으로 만든 브라우저 스네이크 게임입니다. 별도의 설치나 빌드 없이 `index.html`을 브라우저에서 열면 바로 실행됩니다.

## 실행 방법

1. 이 저장소를 내려받습니다.
2. `index.html`을 브라우저로 엽니다.
3. **게임 시작** 버튼을 누르고 방향키로 뱀을 조종합니다.

## 게임 규칙

- 400x400 캔버스, 20x20 격자 위에서 진행됩니다.
- 방향키(↑ ↓ ← →)로 뱀을 조종합니다. 진행 방향의 반대로는 꺾을 수 없습니다.
- 먹이를 먹으면 뱀이 길어지고 10점을 얻습니다.
- 벽이나 자기 몸에 부딪히면 게임 오버입니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 난이도 선택 | 쉬움 200ms / 보통 150ms (기본) / 어려움 100ms / 매우 어려움 50ms. 게임 중에는 변경할 수 없습니다. |
| 레벨 시스템 | 50점마다 레벨업, 레벨업마다 이동 간격이 10ms 줄어 빨라집니다 (최소 30ms). |
| 일시정지 | 버튼으로 일시정지/재개를 전환하며 버튼 글자도 함께 바뀝니다. |
| 최고 점수 | 브라우저 LocalStorage(`snakeBest`)에 저장되어 새로고침해도 유지됩니다. |
| 효과음 | Web Audio API로 합성한 시작·먹이·게임 오버 효과음. 🔊 버튼으로 켜고 끕니다. |
